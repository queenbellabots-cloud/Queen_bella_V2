## 🚀 **Deploy on Katabump**

[![Deploy on Katabump](https://img.shields.io/badge/🚀%20Deploy%20on%20Katabump-FF6B00?style=for-the-badge&logo=rocket)](https://katabump.com/deploy?repo=https://github.com/queenbellabots-cloud/Queer)

### Step 1: Download Repository
- Go to: https://github.com/queenbellabots-cloud/Queer
- Click the green **"Code"** button
- Select **"Download ZIP"**

### Step 2: Upload to Katabump
- Login to your Katabump dashboard
- Click **"Create New Server"**
- Choose **"Upload Files"** method
- Upload the downloaded ZIP file
- Extract the files

### Step 3: Configure Settings
- Open `settings.js`
- Change `ownerNumber` to your WhatsApp number
- Update bot name and owner name if needed

### Step 4: Deploy & Run
- Click **"Deploy"** button
- Wait for the server to start
- Open the console to get your pairing code

### Step 5: Link Your WhatsApp
- Open WhatsApp on your phone
- Go to **Settings → Linked Devices → Link a Device**
- Enter the pairing code shown in the console
